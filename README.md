# 拾光群岛（Isle of Glimmers）隐私政策

生效日期：2026年11月5日  
开发者：javris  
隐私联系邮箱：zhao295994612@gmail.com

## 1. 适用范围

本政策说明《拾光群岛》iOS 版如何处理游戏数据。基础游戏可离线游玩，无需注册游戏账号。当前测试版没有应用内购买，激励广告功能处于关闭状态。

## 2. 保存在设备上的游戏数据

为了保存探险进度和恢复未完成的关卡，游戏会在设备上保存已解锁关卡、星级、分数、未完成的棋盘和剩余步数，以及语言、音效、音乐和减少动态效果等设置。游戏可能保留一份本地备份，用于在主存档损坏时恢复。

这些游戏存档由应用在设备上读写，游戏不会将存档上传到开发者的服务器。Apple 或设备系统可能根据你的设置备份应用数据。游戏本身不提供账号同步或云存档恢复服务。

## 3. 广告与第三方组件

当前测试版包含 Unity LevelPlay 及相关广告组件。游戏关闭了广告功能，不会通过游戏流程初始化广告服务或请求激励广告。

如果未来启用激励广告，我们会在启用前更新本政策，说明实际使用的广告服务商、处理的数据、用途及可用的隐私选择。观看广告将由你自愿选择。

有关 Unity 如何处理个人信息，请参阅 [Unity 隐私政策](https://unity.com/legal/privacy-policy)。

## 4. Apple 服务与反馈

通过 App Store 或 TestFlight 安装和测试游戏时，Apple 可能按照其隐私政策和你的设备设置处理下载、诊断或反馈信息。通过 TestFlight 主动提交反馈时，你提交的说明、截图或 Apple 随反馈提供的信息可能会向开发者显示，用于排查问题。请避免在反馈中附上无关的个人信息。

如果你通过电子邮件联系我们，我们会使用你提供的邮箱和邮件内容回复请求、处理反馈或排查问题。

## 5. 保存、删除与隐私请求

本地存档会保留在设备上，直到你删除 App 或系统清理相关数据。删除 App 可能使本地进度无法恢复，设备备份由你的系统设置管理。

对于开发者收到的反馈或邮件，我们会在处理请求或排查问题所需的期间内保留相关信息。你可以通过本政策所列邮箱询问我们持有的信息，或提出更正、删除等请求。Apple 持有的数据可通过 Apple 提供的隐私管理渠道处理。

## 6. 政策更新与联系

如果游戏功能或数据处理方式发生变化，我们会在本页面更新政策及生效日期。如对本政策有疑问，请联系 [zhao295994612@gmail.com]。
